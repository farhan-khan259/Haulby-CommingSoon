HAULBY — Coming Soon Static Website
===================================

Launch message: 16 November 2026
Contact email: hello@haulby.co.uk

WHAT TO UPLOAD
Upload index.html AND the entire assets/ folder to the document root for haulby.co.uk.
Keep the same directory structure:

  index.html
  assets/
    haulby-logo.webp
    favicon.svg

HOW TO PUBLISH
- Traditional hosting (e.g. Fasthosts): upload the contents to your domain's public_html / web root.
- Vercel or another static host: set the project root to the directory containing index.html, or add the folder to a Git repository and deploy as a static site with no framework build command.
- Ensure haulby.co.uk DNS and HTTPS are correctly configured in your hosting provider.
- Check both haulby.co.uk and www.haulby.co.uk point to the correct site with one preferred canonical URL.

ABOUT THE PAGE
- Pure static HTML and CSS; no JavaScript, forms, cookies, analytics, database or backend required.
- Email buttons open the visitor's default email application; the actual inbox must be configured and working independently.
- Mobile-friendly and keyboard accessible.
- The page deliberately does not offer live bookings before launch.

LEGAL / RELEASE CHECKS
- Verify company disclosures required by UK law once Haulby Ltd is incorporated, including registered company name, company number, registered office, and registration jurisdiction. These are not shown until actual details are confirmed.
- Add a Privacy Policy and Cookie Policy if/when collecting data or embedding non-essential tools (not required by this static version, which collects no data itself).
- Replace this static page with the completed, tested HAULBY platform only when the business is ready for nationwide launch.
